域偏移：格式脱敏 vs 语义改写

PRM 对 32B 老师 CoT 打极低分的根因是措辞分布偏移，不是 markdown 格式。

结论： 语义改写（32B 改写为简洁逐步风格）把 PRM 分数翻倍（0.10 → 0.215），并让生成长度 390→146 token，从根源缓解域偏移；格式脱敏几乎无效。

如何读这个 Benchmark

准确率

抽取「最终答案: X」与标准答案比对，只衡量最终正确性，不衡量推理质量。

PRM 指标

步级 AUC / 错误步召回 / 正确步召回，衡量过程监督模型本身的判别力。

评测口径

CMB hold-out 200 题，与训练/PRM 源严格按题目互斥；temperature 0 确定性评测。

数据口径：CMB（FreedomIntelligence）· 评测集 data/eval/cmb_eval_200.jsonl · 基座 Qwen2.5-7B-Instruct。详细协议见 README.md / README1.md。
