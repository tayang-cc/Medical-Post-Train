# README3 · 全流程实例变化展示

> 用一个直观视角回答「这次 PRM 升级到底改了什么」：同一批医学问题，经过**数据层（语义改写）、奖励层（PRM 打分）、模型层（SFT/GRPO）**三道工序后，发生了什么可见的变化。
>
> 评测集为 CMB hold-out 200 题（与训练/PRM 源严格按题目互斥），基座 Qwen2.5-7B-Instruct。

---

## 1. 一句话总览

| 阶段 | 输入 → 输出 | 关键指标变化 |
|---|---|---|
| **数据层** | 32B markdown CoT → 简洁逐步 CoT | PRM min-score 均值 **0.10 → 0.22**；生成长度 390 → 146 token |
| **奖励层** | 无判别力的 Judge → 步级 PRM | PRM step AUC **0.935**、错误步召回 0.86 |
| **模型层** | 基座 → SFT → GRPO | 准确率 **73.5% → 78.0%（+4.5pp）** |

---

## 2. 数据层实例：同一道题的 CoT 改写

> 题：**HIV 患者最常感染的是下列哪种肺炎**（标准答案 D）

### 改写前：32B 老师的 markdown 风格（冗长、逐选项）

```
HIV（人类免疫缺陷病毒）患者由于其免疫系统受损，因此对于各种感染非常敏感，尤其是机会性感染。

1. **大叶性肺炎**：这是由细菌（如肺炎链球菌）引起的急性炎症，主要影响肺的一个或多个区域。
   这种类型的肺炎在一般人群中较为常见，并非HIV患者的特异性感染。

2. **小叶性肺炎**：这是一种局限于肺小叶的急性细菌性炎症……并非其最常感染类型。

3. **非典型肺炎**：……并不是该群体中最常见的感染源。

4. **卡氏囊虫性肺炎**：卡氏肺孢子虫是一种机会性寄生虫……这在HIV患者中非常常见……
```

### 改写后：简洁逐步风格（7 句话）

```
HIV患者免疫系统受损，易受机会性感染。
大叶性肺炎由肺炎链球菌引起，常见于一般人群，不是HIV患者特异性感染。
小叶性肺炎由多种细菌引起，HIV患者可能发生，但不是最常见的类型。
非典型肺炎由支原体、衣原体等引起，可以感染HIV患者，但不是最常见的感染源。
卡氏囊虫性肺炎由机会性寄生虫卡氏肺孢子虫引起，在HIV患者中非常常见，特别是CD4+ T细胞计数低时。
病毒性肺炎可由多种病毒引起，HIV患者可能感染，但不如卡氏肺孢子虫感染普遍。
HIV患者最常感染的肺炎是卡氏囊虫性肺炎。
```

**发生了什么**：推理要点、医学事实、结论**完全保留**（改写后 99% 答案一致），但去掉了加粗/编号/标题等 markdown 装饰，并压缩了冗余措辞。这正是缓解「域偏移」的关键——PRM 是用 7B 简洁风格轨迹训练的，对 32B 的详细风格打分失准。

---

## 3. 奖励层实例：PRM 分数分布右移

对同一批 CoT 打 min-step 分（PRM），改写前后分布变化：

| 处理方式 | PRM min-score 均值 | 变化 |
|---|---|---|
| 原始 32B CoT | 0.101 | 基线 |
| 格式脱敏（只去 markdown） | 0.120 | +0.019，几乎无效 |
| **语义改写（简洁风格）** | **0.215** | **翻倍，有效** |

**读法**：PRM 给「改写后」的简洁 CoT 打的分数整体翻倍，说明它终于「认得」这种风格了。之前它把 32B 的正确推理也打成 ~0.1（域偏移），导致过程奖励几乎不区分好坏——这也是 GRPO 之前涨不动的根因。

---

## 4. 模型层实例：准确率演进

同一批 CMB-200 评测题，各阶段模型的表现：

| 模型 | acc | 生成长度 | 说明 |
|---|---|---|---|
| 基座 7B | 73.5% | 277 | 零样本 |
| 旧 SFT（1605 脏 CoT） | 68.0% | 398 | **反降**（脏数据过拟合） |
| SFT_clean（PRM 软过滤 1185 条） | 75.0% | 390 | PRM 清洗翻正 +1.5pp |
| SFT_rewrite（语义改写 + 软过滤 1432 条） | 77.5% | **146** | 再 +2.5pp，且风格对齐 |
| **GRPO v3（SFT_rewrite + PRM 奖励）** | **78.0%** | 120 | 最终 +4.5pp |

**三个可见的变化**：
1. **acc**：73.5 → 78.0，+4.5pp；
2. **生成长度**：390 → 146 token（风格从冗长 markdown 变成简洁逐步）；
3. **SFT 从有害翻正**：68.0（反降）→ 77.5（有益），PRM 清洗 + 语义改写是关键。

## 5. 完整闭环视角

```
        数据层                          奖励层                    模型层
  32B CoT ──语义改写──▶ 简洁 CoT   PRM 打分 0.10→0.22   SFT 68%→77.5%
        （去措辞偏移）            （步级 AUC 0.935）      GRPO 77.5%→78.0%
```

三道工序环环相扣：**语义改写**让数据风格对齐 PRM 分布 → **PRM** 打分才有判别力 → 过程奖励可信 → **GRPO** 才能真正起效。三者缺一，RL 增益都只停留在 +1% 甚至反降。

## 6. 附：一条「改写前后」完整对照（第二例）

> 题：**常用细胞生物学技术不包括**（标准答案 E）

- **原始 32B CoT**（前 250 字）：
  ```
  首先明确题目是关于细胞生物学技术的选择题，并要求选出一个不属于常用细胞生物学技术的选项。
  1. **形态学观察**（A）: 这是一种基本的细胞生物学研究方法，通过显微镜观察细胞结构……
  2. **免疫细胞化学**（B）: 这种技术用于检测细胞内的特定蛋白质……
  3. **流式细胞分选术**（C）: 该技术可以快速准确地分析和分离混合细胞群体……
  4. **细胞融合技……
  ```
- **改写后 CoT**：
  ```
  形态学观察是常用细胞生物学技术。
  免疫细胞化学也是常用细胞生物学技术。
  流式细胞分选术是重要细胞生物学实验手段。
  细胞融合技术常用于创造杂交细胞或研究细胞间相互作用。
  载体和宿主细胞技术主要用于基因工程，不典型为细胞生物学技术。
  最终答案是E。
  ```
- PRM min-score（改写后）0.3905。

同样：结论保留、推理完整，但表达从「markdown 分点长句」变成「一行一句的简洁判断」，PRM 打分显著更可信。
